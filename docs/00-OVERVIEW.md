# 00 — Overview

## 1. What we are building

**Hexhaven** is a complete, polished, single-machine 3D strategy board game for 3–4 players (any mix of humans in hot-seat and CPU opponents at three difficulty levels), built in Unity. Players settle a hex-tiled island, harvest resources when dice roll their numbers, trade, build Paths/Outposts/Keeps, buy Charter cards, fight over the Storm, and race to 10 Victory Points.

It belongs to the "hex resource-trading" genre and implements the genre's full classic mechanics with **no rule simplifications**. It is an **original game**: its own name, terminology, art direction, colours, layout and UI. Never use the name, terminology, card names, art, logos or trade dress of any existing commercial board game anywhere in code, assets, strings or docs.

## 2. Pillars

1. **Rules-complete.** Every rule in `01-RULES.md` is implemented exactly, including the edge cases. No "random instead of choice" shortcuts: humans choose discards, steal victims, Bounty/Decree resources, trade terms.
2. **Readable, tactile 3D.** A cosy low-poly diorama island; every game event has a clear animation and sound; the board is always legible (numbers, harbors, ownership).
3. **Fair, competent AI.** Bots play by the same rules and see only public information (plus their own hand). Three difficulties that feel different.
4. **Deterministic and testable.** Pure C# rules engine, seeded RNG, every game is replayable from `(config, action log)`. 10,000 simulated bot games run headless without a single invariant violation.
5. **Zero imported assets.** All meshes, textures, sounds and UI are generated by code or authored as text (UXML/USS). The project builds from a clean clone.

## 3. Scope

### In scope (all required for "done")
- 3 or 4 players; each seat Human / CPU-Easy / CPU-Normal / CPU-Hard.
- Board modes: **Balanced Random** (default), **Random**, **Beginner** (fixed layout).
- Full rules: setup roll-off, snake setup, production with bank shortage, 7 → discard (chosen) → Storm → steal (chosen victim), building with piece limits, 25 Charter cards (5 types) with all play restrictions, domestic trading with offers/counter-offers/multiple partners, maritime trading 4:1 / 3:1 / 2:1, Longest Path and Strongest Guard awards with all tie/break rules, hidden Monument VP, configurable victory target, optional Friendly Storm variant.
- Hot-seat privacy (pass-the-device curtain) when 2+ humans.
- Save/Load: autosave every action + 3 manual slots; Continue from title.
- Settings (audio, bot speed, camera, UI scale, colour-blind emblems, display).
- Full UI: title, new game, HUD, all dialogs, charter hand, log, rules reference, pause, game-over statistics.
- 3D: procedural island, animated ocean, terrain dioramas, number tokens, harbors, pieces, Storm cloud, 3D dice, resource fly-outs, particles, camera rig.
- Procedurally synthesised SFX and an ambient music loop.
- Tests: EditMode rule tests, headless simulation harness, replay/save determinism, PlayMode smoke test, screenshot review.
- Standalone builds for Windows/macOS/Linux.

### Out of scope (do not build)
Online/LAN multiplayer, expansions (5–6 players, seafaring, etc.), mobile/touch controls, localisation beyond English (but keep all strings centralised in `Strings.cs`), achievements, accounts, analytics, monetisation.

## 4. Technical targets

| Item | Target |
|---|---|
| Engine | Unity **6000.0 LTS** (Unity 6). Must also compile on 2022.3 LTS where noted APIs allow; Unity 6 is the reference. |
| Render pipeline | **URP** (project created from the Universal 3D template). Code must not crash in Built-in (material helper falls back), but URP is the reference look. |
| Input | **Input System** package (`com.unity.inputsystem`), Active Input Handling = Input System Package (New). All input goes through `InputShim`. |
| UI | **UI Toolkit** runtime (UXML/USS in `Resources`), PanelSettings created at runtime. IMGUI only for the debug overlay. |
| World text | Legacy `TextMesh` with the built-in `LegacyRuntime.ttf` (no TextMeshPro, avoids the TMP Essentials import prompt). |
| Language | **C# 7.2 syntax everywhere** (Core, Runtime, Editor, Tests) so `tools/compile-check.sh` and the headless harness can build everything with Mono `mcs`. Unity APIs used must exist in 2021.3 (the reference DLLs); guard any Unity-6-only API with `#if UNITY_6000_0_OR_NEWER` plus a fallback. |
| Resolution | 1280×720 minimum, 1920×1080 reference; supports 16:9, 16:10, 21:9, windowed and fullscreen. |
| Performance | ≥ 60 fps at 1080p on integrated GPU class hardware (Intel Iris Xe); ≤ 250 draw calls in game view; no per-frame GC allocations in steady state except UI text updates on change. |
| Startup | Title screen visible < 3 s after launch in a build. |

## 5. Glossary (use these exact terms in code, UI and docs)

| Term | Meaning |
|---|---|
| **Tile** | One of 19 land hexes. |
| **Terrain** | Forest, Clay Pit, Flax Field, Farmland, Mine, Ruins. |
| **Resource** | Timber (Forest), Clay (Clay Pit), Fiber (Flax Field), Grain (Farmland), Iron (Mine). Ruins produce nothing. |
| **Number token** | 2–12 except 7, placed on every non-Ruins tile. **Pips** = number of 2d6 combinations that roll it (2→1 … 6/8→5). |
| **Corner / Vertex** | Intersection of up to 3 tiles; 54 on the board. Outposts and Keeps go here. |
| **Edge** | Border between corners; 72 on the board. Paths go here. |
| **Path** | Road-like piece on an edge. 15 per player. |
| **Outpost** | Small settlement on a corner, 1 VP. 5 per player. |
| **Keep** | Upgrade of an Outpost, 2 VP, harvests double. 4 per player. |
| **Storm** | The blocking piece; starts on Ruins; moved on a 7 or by a Warden. |
| **Harbor** | Coastal trade post on an edge; its 2 corners grant a better maritime rate (Generic 3:1 or a specific 2:1). |
| **Bank** | Supply of 19 cards of each resource and the Charter deck. |
| **Charter** | Development-style card: Warden, Monument, Road Crew, Bounty, Decree. |
| **Warden** | Charter: move the Storm and plunder. Played Wardens count toward Strongest Guard. |
| **Monument** | Charter: hidden 1 VP. |
| **Road Crew** | Charter: place 2 Paths free. |
| **Bounty** | Charter: take any 2 resources from the bank. |
| **Decree** | Charter: name a resource; every opponent gives you all of it. |
| **Longest Path** | Award (+2 VP) for the longest continuous Path of ≥ 5 segments. |
| **Strongest Guard** | Award (+2 VP) for the most Wardens played, minimum 3. |
| **VP** | Victory Points. Public VP excludes hidden Monuments. |
| **Turn** | One player's turn. **Round** = every player has had one turn. |
| **Seat** | Player slot 0–3, fixed clockwise order; seat colours: 0 Crimson, 1 Azure, 2 Amber, 3 Violet. |
